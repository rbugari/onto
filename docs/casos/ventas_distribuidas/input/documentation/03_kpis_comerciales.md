# KPIs comerciales

KPI Ventas netas: suma de importe_neto de pedidos facturados, sin anulados.
KPI Margen %: margen bruto dividido ventas netas.
KPI Cumplimiento de presupuesto: ventas netas del mes dividido importe objetivo de la zona.
KPI Conversion de pipeline: oportunidades ganadas con pedido facturado dividido oportunidades cerradas.
Indicador Cobertura de stock: stock disponible dividido venta promedio diaria de los ultimos 90 dias.

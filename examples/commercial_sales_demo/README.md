# Commercial Sales Demo

Demo sintetica de ONTO para el dominio comercial de ventas.

El caso demuestra:

- metadata tecnica parcial;
- documentacion funcional limitada;
- assessment Atlas con gaps;
- candidatos y release revisada en Nexo;
- consulta de contexto y abstencion en Argos;
- paquete de mapping local sin publicacion externa.

No contiene datos reales de clientes. Se ejecuta con:

```powershell
python scripts/run_commercial_sales_demo.py
```

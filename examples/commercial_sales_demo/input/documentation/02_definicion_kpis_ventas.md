# Definicion de KPIs de ventas

## Ventas netas

KPI para analizar el importe vendido despues de descuentos.

## Margen bruto

KPI para comparar ventas netas con el coste de los productos.

## Clientes activos

KPI propuesto para contar clientes con actividad comercial reciente. Falta definir el periodo exacto y el tratamiento de devoluciones.

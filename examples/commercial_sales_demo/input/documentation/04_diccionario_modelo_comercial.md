# Diccionario parcial del modelo comercial

- `DimCustomer.CustomerKey`: identificador tecnico del cliente.
- `DimCustomer.Region`: region comercial del cliente.
- `FactSales.NetSales`: importe de venta neta.
- `FactSales.GrossMargin`: margen bruto calculado.
- `DimProduct.ProductKey`: identificador tecnico del producto.

No se dispone de definiciones funcionales para todas las columnas.
